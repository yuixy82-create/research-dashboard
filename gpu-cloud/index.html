⑧ 프론티어 랩 매출 — Gross 기준 ($B) 진한 올리브 = 앤스로픽 발표 · 연한 올리브 = 앤스로픽 티커트랜드 · 청록 = 오픈AI
클라우드 가격을 떠받치는 최종 수요. 연환산(run-rate) = 해당 시점 월매출 × 12이며 연간 실적이 아님
Gross = CSP 수익배분 차감 전 매출. 앤스로픽은 이 기준으로 발표하고, 오픈AI는 투자자 자료로만 공개함 (26.07 $40B, 26.09 $68B)
앤스로픽 마지막 점 = 26.10.14 투자자 행사에서 공개한 3분기(7~9월) 실매출 $16.8B × 4. 7~9월 평균이라 분기 한가운데에 찍음

연한 올리브 = 티커트랜드 앤스로픽 추정. 발표가 느려 최근 흐름 참고용이나 금액은 발표치보다 높게 잡힘 (26.07 +14%)
속 빈 점 = 추정. 오픈AI는 Net ÷ 0.73으로 역산 (실측 Net/Gross 비율 26.07 0.75, 26.09 0.74). 25년 이전은 비율 확인 불가라 비워 둠

⑨ 프론티어 랩 매출 — Net 기준 ($B) 진한 올리브 = 앤스로픽(환산) · 연한 올리브 = 티커트랜드(환산) · 청록 = 오픈AI
Net = CSP를 통해 판 API 매출에서 CSP 몫(인프라 비용 차감 후 20~30%)을 뺀 매출. 오픈AI는 26년 초부터 이 기준으로 발표

진한 막대 = 그 달에 보도가 있던 달 · 연한 막대 = 보도 없이 보간만 한 달, 또는 앤스로픽 마지막 발표(26.08) 이후 티커트랜드 추세를 발표치 수준에 맞춰 이은 달(추정)
